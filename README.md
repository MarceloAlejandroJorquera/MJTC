Marcelo Jorquera's Torrent Client

A lightweight desktop torrent client designed for simplicity, speed, and reliability.

🚀 Getting Started

Installation

  Download and install the application.
  If Windows asks for confirmation, allow the app to run.
  Launch the app from the Start Menu or desktop shortcut.
  If this is your first install, Windows may ask you to trust the app certificate. Accept it to continue.

📥 Downloading Torrents

Option 1: Open a .torrent file
  Click Open Torrent.
  Select a .torrent file from your computer.
  Choose a download location.
  Click Start.

Option 2: Magnet link
  Copy a magnet link.
  Click Add Magnet Link.
  Paste the link and confirm.

📂 Managing Downloads

  Pause / Resume: Temporarily stop or continue a download.
  Remove: Deletes the torrent from the list (optionally deletes files).
  Progress Bar: Shows download completion and speed.
  Status: Indicates downloading, seeding, paused, or completed.

⚙️ Settings

In Settings, you can:
  Change the default download folder
  Set bandwidth limits
  Enable or disable auto-start on launch
  Control seeding behavior

🔐 Security & Privacy

  Uses secure peer connections
  No user data is collected
  Runs entirely on your local machine

🛠 Troubleshooting

  App won’t start: Ensure the certificate is trusted.
  Slow downloads: Check bandwidth limits and seed availability.
  Blocked by firewall: Allow the app through Windows Firewall.
